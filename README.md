# SVIT Career Hub / Student Hub 🚀

A comprehensive student portal and career placement ecosystem designed for engineering students.

## ✨ Features

- **College & Academic Explorer**: Interactive academic roadmaps, syllabus guides, and department breakdowns.
- **Career & Placement Tracker**: Real-time mock placement statistics, company drives, eligibility checkers, and salary trends.
- **Student Toolkit**: Resume scoring tools, CGPA calculators, technical interview prep questions, and cheat sheets.
- **Community Forum**: Peer-to-peer discussions, alumni Q&A, and mentorship threads.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (Glassmorphic design system), Vanilla JavaScript (Modular ES6+)
- **Architecture**: Dynamic Client-Side Routing & Component-driven modules

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/madhurathod210-art/svit-career-hub-.git
   ```
2. Open `index.html` in any modern web browser.
